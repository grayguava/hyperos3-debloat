# Safe profile

Detail file for `lists/safe.txt` (33 packages). Low-risk removals: telemetry, bloat and standalone apps — nothing here breaks a system feature. Some are everyday apps you will naturally want a replacement for (browser, videos, music, gallery); those carry a recommended alternative below.

- MIUI Analytics
  - `com.miui.analytics`
  - Xiaomi usage/telemetry collector.
- Xiaomi Joyose
  - `com.xiaomi.joyose`
  - Game/performance telemetry service.
- Mi Pay (payment SDK)
  - `com.xiaomi.payment`
  - Mi Pay payment SDK.
- MIUI Yellow Page
  - `com.miui.yellowpage`
  - Business-number lookup directory.
- Xiaomi Discover feed
  - `com.xiaomi.discover`
  - Content/discovery feed.
- Xiaomi Barrage
  - `com.xiaomi.barrage`
  - Overlay bullet-comment service.
- MIUI Phrase
  - `com.miui.phrase`
  - Predictive-text phrase provider.
- MIUI Compass
  - `com.miui.compass`
  - Compass app.
- MiSight telemetry
  - `com.miui.misightservice`
  - Crash/diagnostic telemetry.
- MIUI QR scanner
  - `com.miui.qr`
  - Standalone QR scanner.
- FM Radio service
  - `com.miui.fmservice`
  - FM radio background service.
- FM Radio app
  - `com.miui.fm`
  - FM radio UI. Only matters with FM hardware/use.
- Downloads UI (MIUI variant)
  - `com.android.providers.downloads.ui`
  - MIUI downloads UI. `com.android.providers.downloads` itself stays.
- Mi App Finder
  - `com.mi.appfinder`
  - On-device search service (part of App Vault) that powers home-screen search and pulls in online suggestions (themes, videos, music). Holds broad permissions and hooks into the system ad provider.
  - Removing it only loses the online suggestions. App-drawer search and the Settings app list keep working after a reboot.
- Facebook App Manager
  - `com.facebook.appmanager`
  - Preinstalled Facebook updater/manager.
- Facebook Services
  - `com.facebook.services`
  - Preinstalled Facebook background services.
- Facebook System
  - `com.facebook.system`
  - Preinstalled Facebook system component.
- Google Docs
  - `com.google.android.apps.docs`
  - Standalone docs app, no dependencies.
- Google One
  - `com.google.android.apps.subscriptions.red`
  - Google One membership app.
- Google TV
  - `com.google.android.videos`
  - Google TV / Play Movies app.
- Google Meet
  - `com.google.android.apps.tachyon`
  - Video-meetings app.
- Google Photos
  - `com.google.android.apps.photos`
  - Photos backup/gallery app.
  - Recommended alternative: [Ente Photos](https://ente.com)
- YouTube
  - `com.google.android.youtube`
  - YouTube app.
  - Recommended alternative: [LibreTube](https://github.com/libre-tube/LibreTube) or [NewPipe](https://github.com/TeamNewPipe/NewPipe)
- YouTube Music
  - `com.google.android.apps.youtube.music`
  - Music streaming app.
  - Recommended alternative: [Metrolist](https://github.com/MetrolistGroup/Metrolist)
- Google Gemini
  - `com.google.android.apps.bard`
  - Gemini AI app (formerly Bard).
- Google Chrome
  - `com.android.chrome`
  - Default Android browser.
  - Recommended alternative: [Cromite](https://github.com/uazo/cromite)
- Privacy Sandbox API
  - `com.google.android.adservices.api`
  - Ad Services API surface.
- Ad Services module
  - `com.google.mainline.adservices`
  - Mainline ad-services module.
- On-device Personalization
  - `com.google.android.ondevicepersonalization.services`
  - Ad-targeting personalization service.
- Location History
  - `com.google.android.gms.location.history`
  - Google location-history component.
- Federated Compute
  - `com.google.android.federatedcompute`
  - Background ML/telemetry compute.
- Print recommendation
  - `com.google.android.printservice.recommendation`
  - Print-service suggestion plugin.
- Google Play Games
  - `com.google.android.play.games`
  - Games hub/achievements app.
